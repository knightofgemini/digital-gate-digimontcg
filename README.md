# Tagli della Home (Digital Gate)

Ramo scritto dall'app (editor "Tagli della Home", con la chiave GitHub dell'utente) e letto dall'app di tutti
all'avvio: `tagli.json` (`immagini`: originali per codice prodotto; `tagli`: `CODICE__hero|cover|square`,
`CODICE__hero@s|m|l|f` per i telefoni sganciati, rettangoli in frazioni dell'originale) e `img/` (originali).
Non cancellare questo ramo.
