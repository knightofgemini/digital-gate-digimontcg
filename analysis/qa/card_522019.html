What does "by placing the top card of this Digimon [...] as this Digimon's bottom digivolution card" in this card's inherited effect mean, exactly?Mar. 28, 2024 Updated
A3527

Q6037

A6037
Yes, it does.
You can reference the number of your opponent's Digimon for "gain 1 memory for each Digimon deleted" even when multiple Digimon are deleted. Even if multiple opponent's Digimon are deleted at the same time, this effect gives you 1 memory for each one deleted.
Q6038
Does this card's [All Turns] effect give me 1 memory for each deletion if both my Digimon and my opponent's Digimon are deleted at the same time in cases such as a "delete 2 Digimon" effect?Mar. 13, 2026 Updated
A6038
You only gain 1 memory for each opponent's Digimon deleted.
You can reference the number of your opponent's Digimon for "gain 1 memory for each Digimon deleted" even when multiple Digimon are deleted. However, you can't include any of your Digimon that are deleted at the same time.
