Keyword Effects Security A.
Q127
What does <Security A.> (formerly <Security Attack>) do?Nov. 21, 2025 Updated
A127
<Security A.> is a keyword effect where the Digimon with this effect will have a modified number of security checks according to the number specified for this effect.
For example, a Digimon with 1 instance of <Security A. +1> will perform 2 security checks.
On the other hand, a Digimon with 1 instance of <Security A. -1> will perform 0 security checks. In addition, even if your Digimon that would perform 0 security checks attacks a player with 0 cards in their security stack, you don't yet win the game.
Q128
If 1 Digimon has multiple instances of <Security A. +1>, does the number of security checks performed increase accordingly?Nov. 21, 2025 Updated
A128
Yes, they do.
For example, a Digimon with 2 instances of <Security A. +1> will perform 3 security checks.
Q129
If a Digimon with <Security A. +1> will perform security checks, are 2 security cards flipped over at the same time?Nov. 21, 2025 Updated
A129
No, 2 security cards aren't flipped over at the same time.
Even if multiple security checks are to be performed, the checks are performed 1 card at a time.
Q130
If 1 Digimon has multiple instances of <Security A. -1>, does the number of security checks performed decrease accordingly?Nov. 21, 2025 Updated
A130
Yes, they do.
For example, a Digimon with 2 instances of <Security A. -1> will perform 0 security checks.
Even if the number of security checks is a negative value, the actual number of security checks is 0.
Q131
If a Digimon has 1 instance of <Security A. +1> and 1 instance of <Security A. -1>, how many security checks does it perform?Nov. 21, 2025 Updated
A131
1 card.
The number of security checks to be performed according to <Security A.> is first calculated, then they are added to the Digimon.
In this case, +1 and -1 are first applied to the number of security checks to be performed, resulting in 0, so 0 checks are applied to the Digimon. The Digimon can originally perform 1 security check, therefore this results in 1 security check that can be performed.
Q132
If 1 Digimon has 2 instances of <Security A. +1>, is that effect considered to be <Security A. +2>?Nov. 21, 2025 Updated
A132
No, it isn't.
It is considered a Digimon with 2 instances of <Security A. +1>. Even if a card has multiple instances of <Security A.>, the effect isn't considered to be an effect with the combined values from <Security A.>.
Q133
A Digimon performed 1 security check.
At such times, if the Digimon that performed the security check gains <Security A. +1> from an effect, does it perform the 1st security check, and then perform 1 more security check?Nov. 21, 2025 Updated
A133
Yes, another security check is performed.
After performing a security check and gaining <Security A.>, the number of security checks will be modified.
Q134
A Digimon with <Security A. +1> performed 1 security check.
At such times, if the Digimon that performed the security check gains <Security A. -1> from an effect, does it perform the 1st security check, and then perform 1 more security check?Nov. 21, 2025 Updated
A134
No, the 2nd security check isn't performed.
After a Digimon gains <Security A.>, the number of security checks will be immediately modified.
Q135
A Digimon with <Security A. +1> performed 1 security check.
At such times, if the Digimon that performed the security check loses <Security A. +1>, does it perform the 1st security check, and then perform 1 more security check?Nov. 21, 2025 Updated
A135
No, the 2nd security check isn't performed.
After a Digimon loses <Security A.>, the number of security checks will be immediately modified.
Keyword Effects Blocker
Q136
What does <Blocker> do?Nov. 21, 2025 Updated
A136
<Blocker> is a keyword effect that applies a rule that allows a Digimon with that effect to block.
A block can only be performed once per attack during the opponent's block timing.
You can suspend one of your Digimon with <Blocker> in the battle area to switch the attack target to the blocking Digimon.

Keyword Effects Piercing
Q149
What does <Piercing> do?Mar. 6, 2026 Updated
A149
<Piercing> is a keyword effect that reads "when this attacking Digimon deletes your opponent's Digimon in battle, it performs a security check before the attack ends."
When a Digimon with <Piercing> attacks and deletes an opponent's Digimon in battle during that attack, <Piercing> will activate.
If <Piercing> activates, that Digimon will perform a security check on the opponent immediately before the end of attack timing.
If <Piercing> triggers, it must activate and a security check must be performed when possible.
Q150
The attack target of a Digimon with <Piercing> changed to an opponent's Digimon, then a battle with that Digimon occurred.
If only the opponent's Digimon is deleted in that battle at such times, do I use <Piercing> to perform a security check immediately before the end of attack timing?Mar. 6, 2026 Updated
A150
Yes, you do.
Q151
A Digimon with <Piercing> and an opponent's Security Digimon battle.
If the Digimon with <Piercing> wins the battle against the opponent's Security Digimon, do I use <Piercing> to perform a security check immediately before the end of attack timing?Mar. 6, 2026 Updated
A151
No, you don't.
Q152
During an attack by a Digimon with <Piercing>, it battled a Digimon, then both Digimon lost and were deleted in battle.
At such times, do I use <Piercing> to perform a security check immediately before the end of attack timing?Mar. 6, 2026 Updated
A152
No, you don't.
Q153
During an attack by a Digimon with multiple instances of <Piercing>, if only an opponent's Digimon is deleted in that battle, do I use <Piercing> the corresponding number of times to perform security checks immediately before the end of attack timing?Mar. 6, 2026 Updated
A153
No, you only perform 1 security check for <Piercing>.
Only 1 security check can be performed during a single attack, even if <Piercing> activates multiple times.
However, if the number of security checks is modified by <Security A.>, that number of cards will be checked in a single security check.
Q154
During an attack by a Digimon with <Piercing>, does <Piercing> trigger even if a battle with that Digimon occurs by an effect and only an opponent's Digimon is deleted?Feb. 6, 2026 Updated
A154
Yes, it triggers.
Q155
A Digimon with <Piercing> attacked the opponent player, a battle with that Digimon occurs by an effect, and only an opponent's Digimon is deleted in the battle.
After that, if the attack on the opponent player is successful, do I perform a security check, then use <Piercing> to again perform a security check immediately before the end of attack timing?Mar. 6, 2026 Updated
A155
No, you don't use <Piercing> to perform a security check.
<Piercing> is an effect that can be used to perform a security check immediately before the end of attack timing, but only if the attack on the opponent player isn't successful. If the attack on the opponent player is successful, a security check can't be performed using <Piercing>.
Q156
A Digimon with <Piercing> attacked an opponent's Digimon, a battle with that Digimon occurs by an effect, and only an opponent's Digimon is deleted in the battle.
Then, only an opponent's Digimon is again deleted in the battle with the attack target opponent Digimon, and a security check was performed.
Do I then use <Piercing> to again perform a security check immediately before the end of attack timing?Mar. 6, 2026 Updated
A156
No, you don't use <Piercing> to perform a security check.
Even if a Digimon with <Piercing> battles multiple times during 1 attack and opponent Digimon are deleted during those battles, only 1 security check can be performed during a single attack.
However, if the number of security checks is modified by <Security A.>, that number of cards will be checked in a single security check.

A159
Draw as many cards as you can. If you run out of cards to draw, the effect ends.

Keyword Effects Reboot

Keyword Effects De-Digivolve
Q165
A level 4 Digimon that digivolved from a level 2 Digi-Egg loses its level 3 digivolution card due to an effect, resulting in a level 4 Digimon card on top of a level 2 Digi-Egg card. If you activate <De-Digivolve> on it, does the level 2 card remain in the battle area? What happens to the Digimon?Mar. 28, 2024 Updated
A165
Level 2 Digimon can't remain in battle areas, so it's sent to the trash. (The Digimon is not considered to have been deleted.)
Q166
If a Digimon has activated an effect then <De-Digivolve> causes the card with the effect to be trashed, is the effect lost?Mar. 28, 2024 Updated
A166
If the effect lasts for a specified period of time (such as "for the turn" or "until the end of your opponent's turn), the effect will persist until the end of the time specified, even if the card with the effect is trashed by <De-Digivolve>.
Effects that remain activated (such as [Opponent's Turn] and [All Turns]) end immediately once their card is trashed.
Q167
If I activate <De-Digivolve> on a Digimon with a Tamer card in its digivolution cards, can I also trash the Tamer card by using <De-Digivolve>?Mar. 28, 2024 Updated
A167
Yes, Tamer cards that are part of another card's digivolution cards can be chosen by <De-Digivolve>. If there are no other digivolution cards beneath the Tamer card, however, you can't trash any more cards with <De-Digivolve>.
Q168
If I use <De-Digivolve> on a Digimon with a Tamer card in its digivolution cards such that the Tamer card becomes the top-most card in the stack, what happens?Mar. 28, 2024 Updated
A168
The card becomes a Tamer. Note that this doesn't count as the Tamer being played.
Q169
If I activate a card effect to <De-Digivolve 1> a level 6 Digimon with two level 5 Digimon cards in its digivolution cards, what happens?Mar. 28, 2024 Updated
A169
The card stacked on top becomes a Digimon. Even if a card with the same level is in its digivolution cards, it's still treated as a digivolution card.
Q170
If a card trashed by <De-Digivolve> has an [On Deletion] effect, does it activate?Mar. 28, 2024 Updated
A170
No. Trashing by <De-Digivolve> isn't considered deletion, therefore it doesn't activate.
Q171
Can I use <De-Digivolve> to trash a card from an opponent's level 3 Digimon that has a level 3 or higher Digimon card in its digivolution cards due to an effect?Mar. 28, 2024 Updated
A171
No. <De-Digivolve> can't trash a card from a level 3 Digimon even if it has a level 3 or higher Digimon card in its digivolution cards.
Q172
I activated <De-Digivolve 2> and trashed the top 2 cards from a Digimon with cards stacked in the following order from top to bottom: Lv.4 > Lv.2 > Lv.3. Once I trash the top card, does the target Digimon become level 2 and become trashed?Mar. 28, 2024 Updated
A172
No. The cards aren't trashed until <De-Digivolve> finishes activating, even if a Digimon becomes a level 2 Digimon card without DP. If the target Digimon becomes a level 2 Digimon without DP after <De-Digivolve> finishes activating, then it's trashed.
Keyword Effects Retaliation
Q173
I used my Digimon with <Piercing> to attack, and it deleted an opponent's Digimon with <Retaliation> in battle. My attacking Digimon is deleted by <Retaliation>, but what happens to the <Piercing> effect?Mar. 28, 2024 Updated

<Piercing> activates, but because the Digimon with <Piercing> is deleted by <Retaliation> before the security check is performed, the battle ends and you can't perform the security check.
Q174
If I delete an opponent's Digimon with <Retaliation> in battle, does this fulfill the condition for "When this Digimon attacks and deletes an opponent's Digimon and survives the battle"?Mar. 28, 2024 Updated
A174
Yes, it does.
Keyword Effects Digi-Burst
Q175
What does <Digi-Burst> do?Mar. 28, 2024 Updated
A175
It allows you to activate a powerful effect by trashing a specified number of digivolution cards beneath the Digimon with <Digi-Burst>. Effects vary from card to card.
Q177
If I have a Digimon with <Digi-Burst 2> that only has 1 digivolution card under it, can I activate <Digi-Burst 2> by trashing all of its digivolution cards?Mar. 28, 2024 Updated
A177
No, you can't activate <Digi-Burst> unless you trash the specified number of cards.
Q178
Can I trash the digivolution cards under other Digimon to activate <Digi-Burst>?Mar. 28, 2024 Updated
A178
No, you can't.
Q179
When trashing digivolution cards to activate <Digi-Burst>, can I trash them in any order I like, or do I have to trash them in a specific order?Mar. 28, 2024 Updated
A179
You can trash digivolution cards in any order you like.
Q180
If a Digimon's digivolution cards includes a card that isn't a Digimon, can I trash it to activate <Digi-Burst>?Mar. 28, 2024 Updated
A180
Yes. As long as it's a digivolution card, you can trash it to activate <Digi-Burst>.
Q181
If a <Digi-Burst> effect has [Main] attached to it, can I activate it during my main phase?Mar. 28, 2024 Updated
A181
Yes.
Q182
Do I have to suspend a Digimon after it activates <Digi-Burst>?Mar. 28, 2024 Updated
A182
No. Unless otherwise specified, Digimon remain unsuspended after activating <Digi-Burst>.
Q183
Can suspended Digimon activate <Digi-Burst>?Mar. 28, 2024 Updated
A183
Yes, they can.
Q184
If a <Digi-Burst> effect doesn't have [Once Per Turn], can I activate it two or more times per turn?Mar. 28, 2024 Updated
A184
<Digi-Burst> effects with [Main] activations can be activated as many times as you like during a turn, as long as you're able to trash the specified number of digivolution cards each time.
Q185
I digivolve a Digimon that has the effect "[When Digivolving] <Digi-Burst>" -- Can I activate this effect multiple times if I have enough digivolution cards?Mar. 28, 2024 Updated
A185
No, you can't. [When Digivolving] <Digi-Burst> effects can only be activated once per digivolution.
Q186
If an effect specifies a "Digimon with <Digi-Burst>" or a "Digimon card with <Digi-Burst>," does it apply to Digimon whose <Digi-Burst> effects have [On Play] or [When Digivolving] attached?Mar. 28, 2024 Updated
A186
Yes, Digimon whose <Digi-Burst> effects have [On Play]/[When Digivolving]/etc. are also considered to have <Digi-Burst> and are affected by any effect that specifies a "Digimon with <Digi-Burst>."
Keyword Effects Rush
Q187
What does <Rush> do?Mar. 28, 2024 Updated
A187
Digimon with <Rush> can ignore the rule that prevents Digimon from attacking the turn they come into play. In short: Digimon with <Rush> can attack as soon as you play them.
Q188
I pay for a Digimon with <Rush>, putting the memory counter at 1 or greater on my opponent's side. Can the Digimon still attack?Mar. 28, 2024 Updated
A188
No, it can't. <Rush> ignores the rule that prevents Digimon from attacking the turn they come into play, but if it becomes your opponent's turn after you pay the memory cost, you no longer have the opportunity to attack.
Q189
I play a Digimon without <Rush>, then digivolve it into a Digimon with <Rush> during the same turn. Can it attack?Mar. 28, 2024 Updated
A189
Yes, it has <Rush> now, allowing it to attack.
Q190
I play a Digimon with <Rush>, then digivolve it into a Digimon without <Rush> during the same turn. Can it attack?Mar. 28, 2024 Updated
A190
No, it can't. It lost <Rush> after you digivolved it, so it can no longer attack.
Q191
I play a Digimon with <Rush> and attack with it. If I use an effect to unsuspend it, can I attack with it again?Mar. 28, 2024 Updated
A191
Yes, you can.
Keyword Effects Blitz
Q192
What does <Blitz> do?Sep. 5, 2025 Updated
A192
<Blitz> is a keyword effect where a Digimon with this effect can attack if your opponent has 1 or more memory.
"If your opponent has 1 or more memory" refers to when the memory is at 1 on your opponent's side or further to the right.
If attacking with <Blitz>, you suspend the attacking Digimon and choose an attack target, as with a standard attack.
Q193
I digivolved a card into a Digimon card with [When Digivolving] <Blitz>, and the memory moved to 1 or more on my opponent's side.
At such times, if another effect activates first and the memory moves to 0 or more, can I still activate <Blitz>?Sep. 5, 2025 Updated
A193
No.
You can't activate <Blitz> unless the memory gauge is at 1 or greater on your opponent's side.
Q194
I digivolved a card into a Digimon card with [When Digivolving] <Blitz>, and the memory is at 0 or more.
At such times, if another effect activates first and the memory moves to 1 or more on my opponent's side, can I activate <Blitz>?Sep. 5, 2025 Updated
A194
Yes, it can be activated.
Q195
I digivolved a card into a Digimon card with [When Digivolving] <Blitz>, then activated <Blitz> and used that Digimon to attack.
At such times, if another effect activates first and the memory moves to 0 or more, what happens to the attack?Sep. 5, 2025 Updated
A195
The attack continues as-is.
Q196
If a card digivolves into a Digimon card with [When Digivolving] <Blitz> during the same turn it was played, can I use <Blitz> to have it attack?Sep. 5, 2025 Updated
A196
No, you can't.
A Digimon can't attack during the same turn it was played, even when using an effect.
Q197
I use my Digimon to attack, and an effect digivolves it into a Digimon card with [When Digivolving] <Blitz>.
Can I activate the digivolved card's [When Digivolving] <Blitz> and have it attack at such times?Sep. 5, 2025 Updated
A197
No, it can't attack. A new attack declaration can't be made during an attack.
Q198
I digivolved a card into a Digimon with [When Digivolving] <Blitz>, another [When Digivolving] effect, and a [When Attacking] effect, and the memory is at 1 or more on my opponent's side.
If I activate [When Digivolving] <Blitz> first and attack, in what order do the other effects activate?Sep. 5, 2025 Updated
A198
[When Digivolving] <Blitz> and the other [When Digivolving] effect trigger simultaneously, and the [When Attacking] effect is triggered by the attack declaration from <Blitz>, making it a derived trigger.
A derived triggering effect will activate before other triggered effects that are pending activation. Therefore, the [When Attacking] effect will activate before the other [When Digivolving] effect.
Q199
During the main phase, I digivolved a card into a Digimon card with [When Digivolving] <Blitz>, and the memory moved to 1 or more on my opponent's side.
At such times, if <Blitz> activates and that Digimon attacks, in what order do the counter timing and end of turn occur?Sep. 5, 2025 Updated
A199
The end of the turn will occur once all of the processing that occurred from the attack has resolved.
When the memory is at 1 or more on your opponent's side and all processing has been resolved, the turn will end.
In this case, the turn will end after resolving all of the processes (counter timing, block timing, confirming if an attack is successful, and end of attack) that occurred as a result of the attack from <Blitz> and the attack ends.
Q200
At the end of the turn, I digivolved a card into a Digimon card with [When Digivolving] <Blitz>.
At such times, if <Blitz> activates and that Digimon attacks, in what order do the counter timing and end of turn occur?Sep. 5, 2025 Updated
A200
The counter timing will occur once all of the processing that occurred from the end of the turn has resolved.
Once the attack has been declared and all of the processing has been resolved for that timing, the counter timing will occur.
In this case, the counter timing will occur after resolving all of the effects that triggered as a result of the attack from <Blitz> and resolving all of the effects that triggered from the end of the turn.
Keyword Effects Delay
Q207
What does <Delay> do?Mar. 28, 2024 Updated
A207
After placing an Option card with <Delay> in your battle area, you can trash it during your main phase to activate various effects.
Q208
How do I place an Option card with <Delay> in my battle area?Mar. 28, 2024 Updated
A208
The effect to "place an Option card with <Delay> in your battle area" must be activated separately.
Some Option cards with <Delay> have main/security effects that place the card itself in your battle area.
Q209
I have an Option card with <Delay> in my battle area. Can I use it just like a normal Option card?Mar. 28, 2024 Updated
A209
No. Option cards placed in battle areas are treated separately from cards in hand, and only their <Delay> effects can be activated.
Q210
When activating an Option card's <Delay> effect, do I have to pay the Option card's memory cost?Mar. 28, 2024 Updated
A210
No, you don't.
Q211
How many Option cards with <Delay> can I place in my battle area?Mar. 28, 2024 Updated
A211
There's no limit to the number of Option cards you can place in your battle area.
Q212
If I have multiple cards with <Delay> in my battle area, can I activate all of them at once?Mar. 28, 2024 Updated
A212
You can activate multiple <Delay> effects during the same turn. However, you must activate them one at a time. You can't activate multiple <Delay> effects simultaneously.
Q213
Can I return an Option card with <Delay> to my hand instead of activating its <Delay> effect?Mar. 28, 2024 Updated
A213
No. As a general rule, once you place an Option card in your battle area, you can't return it to your hand.
Q214
My opponent has an Option card placed in their battle area. Can I remove it by attacking it with a Digimon?Mar. 28, 2024 Updated
A214
No, you can't.
Q215
Do <Delay> effects count as Option card effects?Mar. 28, 2024 Updated
A215
Yes, they do.
Q216
Can I activate a card's <Delay> effect if I don't have a Digimon or Tamer in play of a matching color?Mar. 28, 2024 Updated
A216
Yes, you can.
Q217
If I activate the <Delay> effect on an Option card in my battle area, does it count as using an Option card?Mar. 28, 2024 Updated
A217
No. Activating the <Delay> effect on an Option card in your battle area doesn't count as using an Option card. As such, activating a <Delay> effect doesn't activate the effects on cards like [BT3-091 Lilithmon] or [BT3-096 Mimi Tachikawa].
Q218
Can an Option card placed in the battle area meet the color requirements when using another Option card?Mar. 28, 2024 Updated
A218
No. Only Digimon and Tamers can be used to meet color requirements. An Option card placed in the battle area doesn't meet color requirements.
Keyword Effects Decoy
Q219
What does <Decoy> do?Mar. 28, 2024 Updated
A219
When one of your Digimon matching <Decoy>'s specifications would be deleted by an opponent's "delete" effect, you can delete the Digimon with <Decoy> instead to prevent the other Digimon from being deleted.
Q220
When can <Decoy> be activated?Mar. 28, 2024 Updated
A220
When one of your Digimon matching <Decoy>'s specifications would be deleted by an opponent's "delete" effect, you can activate <Decoy> before the Digimon is deleted. Think of it as an effect that interrupts deletions.
Q221
What happens to the digivolution cards of a Digimon saved with <Decoy>?Mar. 28, 2024 Updated
A221
They stay in play. The Digimon saved with <Decoy> isn't deleted, and neither are its digivolution cards.
Q222
A Digimon saved with <Decoy> has an [On Deletion] effect. Does the [On Deletion] effect activate?Mar. 28, 2024 Updated
A222
No. A Digimon saved with <Decoy> isn't deleted, so its [On Deletion] effect doesn't activate.
Q223
A Digimon that activated <Decoy> and deleted itself to save another Digimon had an [On Deletion] effect. Does that effect activate?Mar. 28, 2024 Updated
A223
Yes, it does.
Q224
Can I use <Decoy> to save a Digimon that's going to be deleted as a result of battle?Mar. 28, 2024 Updated
A224

A6933
<Detach> is a keyword effect where if the Digimon with this effect would leave the battle area other than by your effects, by trashing 1 of its specified link cards, it doesn't leave.
Keyword Effects Succession
Q6934
What does <Succession> do?Aug. 18, 2026 Updated
A6934
<Succession> is a keyword effect where the Digimon with this effect will gain all effects other than <Succession> on its topmost specified digivolution card.
For example, in the case of <Succession ([Ceresmon])>, the Digimon would gain all other non-<Succession> effects possessed by a card named [Ceresmon] in its digivolution cards.
Note, if the Digimon has multiple digivolution cards named [Ceresmon], it will only gain the effects from the topmost [Ceresmon] digivolution card.
Q6935
If a card with the <Succession> effect is placed on top of a card that has used an [X Per Turn] effect, will it inherit the gained [X Per Turn] effect's usage count?Aug. 18, 2026 Updated
A6935
No. The original card's effects and the effects gained from the <Succession> effect are treated as different effects.
Q6936
I place a card with <Succession> over a card with an unused [X Per Turn] effect then use the gained [X Per Turn] effect the maximum number of times.
If the card with <Succession> placed on top is then removed, leaving behind the card with an unused [X Per Turn] effect, will it inherit the usage count for that [X Per Turn] effect?Aug. 18, 2026 Updated
A6936
No, the usage count is not inherited. The effect on the original card and the effect gained from <Succession> are treated as different effects.
Q6937
I have a Digimon with a [When Digivolving] effect. When that Digimon digivolves into a Digimon card with <Succession>, will the [When Digivolving] effect gained from <Succession> activate?Aug. 18, 2026 Updated
A6937
Yes.
The moment the card is stacked on top to digivolve, the Digimon gains the digivolution card's [When Digivolving] effect from <Succession>.
Therefor, that [When Digivolving] effect can trigger and activate.
Q6938
Does a card with <Succession> gain effects in the lower text, such as inherited and link effects?Aug. 18, 2026 Updated
A6938
No, it does not gain effects in the lower text.
Q6939
Does a card with <Succession> gain text that is not part of an effect, such as (Rules) and DigiXros?Aug. 18, 2026 Updated
A6939
No, it does not gain text that is not part of an effect.
Q6940
An effect gained from <Succession> is pending activation. If the digivolution card with that effect is removed from the digivolution cards before it activates, and the gained effect is lost, can the effect be activated?Aug. 18, 2026 Updated
A6940
No, it cannot. If an effect pending activation is lost before it activates, that effect cannot be activated.
Q6941
If my Digimon digivolves into a Digimon with <Succession> and I activate another effect and place a card with a [When Digivolving] effect into that Digimon's digivolution cards, can I activate that [When Digivolving] effect on the placed card?Aug. 18, 2026 Updated
A6941
No, you can't.
Q6942
After gaining an effect from <Succession>, is the card considered to have that effect's text?Aug. 18, 2026 Updated
A6942
No, it isn't.
Q6943
My Digimon has gained an [On Deletion] effect from <Succession>. When that Digimon is deleted, will it activate that gained [On Deletion] effect?Aug. 18, 2026 Updated
A6943
Yes.
When a card with <Succession> is deleted while it is gaining an [On Deletion] effect, that [On Deletion] effect gained by the card with <Succession> will be pending activation.
Keyword Effects Guard
Q7196
When my Digimon would leave the battle area by an opponent's effect, a Digimon with <Guard> is played by a separate immediate-type effect.
At this time, can I activate <Guard> on the Digimon that came into play to prevent the Digimon that would leave the battle area from leaving?Sep. 18, 2026 Updated
A7196
No, you can't.
<Guard> on the Digimon played by the immediate-type effect can't be activated because the trigger timing for that ability has already passed.
Keyword Effects Succession
Q7197
I currently have a Digimon with <Succession>.
If the card specified by that Digimon's <Succession> ability is not its topmost digivolution card, can it still gain that card's effects?Sep. 18, 2026 Updated
A7197
Yes, it can gain them.
However, if that Digimon has multiple cards specified by <Succession> in its digivolution cards, it only gains the effects of the topmost card among them.
